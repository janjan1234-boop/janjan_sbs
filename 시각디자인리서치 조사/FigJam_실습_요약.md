# FigJam 실습 보드 요약

- 원본: [FigJam 보드](https://www.figma.com/board/jhyua1WTHjXSTye0loAg4m/Untitled?node-id=1-2&t=wbBpAJH3Pne9DJpe-1)
- 확인 범위: 링크의 `예시` 섹션과 그 안의 텍스트, 이미지 배치, 연결 화살표

## 핵심 내용

개인의 관심사와 감각을 키워드로 정리하고, 이를 이미지와 구체적인 질감·장면으로 발전시키는 시각 디자인 실습 보드다. 8명의 키워드와 이미지 레퍼런스가 모여 있으며, 강아지를 소재로 한 모티브 탐색과 표지 레퍼런스, 최종실습 영역이 이어진다.

## 보드의 흐름

보드의 연결 화살표는 다음 순서를 가리킨다.

1. **마인드맵**: 손으로 작성한 마인드맵 사진과 이미지 자료를 모은다.
2. **키워드**: 참여자 8명의 관심사와 표현 방향을 포스트잇으로 정리한다.
3. **강아지 모티브(텍스처)**: 강아지에게서 떠오르는 촉감과 장면을 이미지와 문장으로 탐색한다.
4. **강아지 오너먼트 레퍼런스**: 장식 요소에 참고할 이미지를 모은다.
5. **표지 레퍼런스**: 표지 시안과 참고 이미지를 배치한다.
6. **최종실습**: 참여자별 키워드를 이미지와 짧은 설명으로 구체화한다.

## 참여자별 키워드와 표현 방향

| 참여자 | 주요 키워드 | 보드에서 드러난 표현 방향 |
| --- | --- | --- |
| 강애란 | 디저트, 식물, 강아지, 무대, 생활체육 | 페이스트리의 결, 크림과 털의 질감, 식물의 예측하기 어려운 성장, 복싱 후의 감각, 무대 뒤의 조형을 탐색한다. |
| 박선환 | 정리, 귀여운 캐릭터, 음악, 산책 | 규칙적인 벽돌과 한 방향으로 움직이는 빛, 다양한 캐릭터, 음악의 고조, 낯선 곳을 걷는 느낌을 연결한다. |
| 홍석경 | 키치, 힙, 메탈릭, 몽환, 비정형 | 레트로하고 자유로운 감성, 꿈처럼 흐릿한 기억, 차갑고 빛나는 금속, 틀 없이 흐르는 형태를 표현한다. |
| 김규린 | 유기적 질서, 동물, 파랑·청록, 캐릭터, 젠더 뉴트럴 | 얽힌 요소 속에서 구조를 찾는 감각, 동물의 투명함과 편안함, 하늘과 바다가 주는 파란색의 인상을 탐색한다. |
| 이주원 | 빈티지, 남성적, 직선, 금속, 고전 | 차가운 금속, 달궈져 휘어진 강철, 어려운 환경에서도 서 있는 모습, 기억의 편린을 이미지화한다. |
| 김형관 | 규칙적인 생활, 운동, 그래픽 디자인, 파랑·초록·노랑, 일러스트 | 생활의 안정감과 운동을 통한 성장, 자연의 색, 다양한 자료와 도구를 모아 디자인을 완성하는 과정을 다룬다. |
| 신윤아 | 흑백·파스텔, 차분함, 휴식, 바다·우주, 반추·공허함 | 넓고 빈 공간에 홀로 선 물체, 파도와 오로라, 반복해서 도는 생각, 방해 없는 휴식의 이미지를 모은다. |
| 전해주 | 캐릭터, 게임, 디저트, 포근함, 집 | 게임의 즐거움, 창가의 햇살, 디저트의 향, 작은 캐릭터, 부드러운 섬유의 감각을 담는다. |

## 강아지 모티브 탐색

강아지의 **털결·복슬복슬함·체온**을 중심으로, 눈밭에 남는 발자국, 목줄과 터그 놀이의 끈, 수영 후 몸을 털 때의 물방울, 햇빛을 받으며 누워 있는 포근한 모습 등을 시각 소재로 모았다. 별도의 건축학 모티브 섹션도 있으나, 확인한 보드 텍스트에는 설명이 없다.

## 현재 상태

보드는 확정된 결과물보다 아이디어와 레퍼런스를 모으는 단계로 보인다. 표지 레퍼런스 영역에는 시안과 이미지가 배치되어 있지만, 보드에서 확정된 표지안이나 일정·담당 업무는 확인되지 않는다. 마인드맵은 주로 손글씨 사진으로 구성되어 있어 세부 문구를 모두 전사하지는 않았다.

## 강애란 마인드맵 재구현과 확장

손그림 마인드맵의 중심인 `강애란`에서 `내가 좋아하는 것`과 `내가 싫어하는 것`을 편집 가능한 FigJam 도형으로 다시 구성했다. 읽을 수 있는 손글씨 항목을 도형으로 옮기고 연결선을 추가했다. [도형 마인드맵](https://www.figma.com/board/jhyua1WTHjXSTye0loAg4m/Untitled?node-id=4-72)

원본에서 `강아지`, `복싱`, `무대`, `디저트`를 이어 다음 **시각 키워드 5개**를 추출했다. 각 키워드는 다시 제작에 쓸 수 있는 형태 요소로 번역했다. [추가 마인드맵](https://www.figma.com/board/jhyua1WTHjXSTye0loAg4m/Untitled?node-id=5-260)

| 1차 시각 키워드 | 2차 형태 번역 |
| --- | --- |
| 복슬복슬한 털결 | 물결선, 겹침, 부드러운 윤곽 |
| 발자국의 반복 | 점과 타원, 간격의 리듬 |
| 움직이는 몸의 곡선 | 역동적인 실루엣과 궤적 |
| 겹겹이 쌓인 장면 | 무대의 층, 아치, 깊이 |
| 달콤하고 부드러운 층 | 크림 곡면과 페이스트리 단면 |
