# 모나미 홈페이지 그리드 정리

- 기준 페이지: https://www.monami.com/index.php
- 확인 방법: Playwright MCP 브라우저에서 1920px, 1440px, 390px 뷰포트의 실제 요소 크기 측정
- 목적: `1코딩/모나미/` 재구현 시 참고할 레이아웃 기준

## 전체 구조

| 순서 | 영역 | 원본의 배치 기준 |
| --- | --- | --- |
| 1 | 상단 유틸 메뉴 + 메인 내비게이션 | 화면 전체 너비 배경, 내부 최대 1400px 중앙 정렬 |
| 2 | 메인 비주얼 | 화면 전체 너비, 문구는 최대 1400px 영역 안에 배치 |
| 3 | NEW ARRIVALS | 최대 1200px 중앙 정렬, 비대칭 카드 5개 |
| 4 | BEST PRODUCT | 전체 너비 제목·탭, 가로로 드래그하는 상품 목록 |
| 5 | 브랜드 영상 | 전체 너비 영상 영역 |
| 6 | 뉴스 / 문의 / 브랜드스토어 | 최대 1400px 중앙 정렬, 3열 |
| 7 | 푸터 | 최대 1400px 중앙 정렬, 위·아래 2단 |

## 공통 그리드

- 원본의 넓은 콘텐츠 컨테이너는 `max-width: 1400px`이다. 1920px 화면에서 좌우 시작점은 약 253px이다. 브라우저의 세로 스크롤바를 제외한 콘텐츠 너비 1905px을 기준으로 중앙 정렬된다.
- 1440px 화면에서는 넓은 컨테이너가 약 1340px이며 좌우 여백은 약 43px이다. 원본의 컨테이너가 화면 너비에 따라 줄어드는 점을 고려한다.
- `NEW ARRIVALS`만 별도의 `max-width: 1200px` 컨테이너를 사용한다. 1920px 화면에서 시작점은 약 353px이다.
- 기존 메모의 `margin 20px`은 로컬 재구현용 여백 값으로 유지할 수 있으나, 원본의 모든 구역에 고정된 20px 여백이 적용되는 것은 아니다.
- 배치는 CSS Grid만으로 이루어져 있지 않다. 원본은 고정 크기 카드, 가로 목록, 전체 너비 배경을 조합한다. 재구현에서는 동일한 시각적 그리드를 Grid/Flex로 표현해도 된다.

## 영역별 실측값

### 헤더와 메인 비주얼

- 헤더 전체 높이 약 149px: 유틸 메뉴가 위쪽 약 59px, 메인 내비게이션이 약 89px을 차지한다.
- 메인 내비게이션은 1400px 컨테이너 안에서 로고와 메뉴를 가로로 나란히 놓는다. 1920px 화면에서 로고 영역은 약 162px 너비다.
- 유틸 메뉴의 언어 버튼은 기존 메모대로 약 `88 × 30px`이다.
- 메인 비주얼은 헤더 아래에 놓이며 높이는 약 652px이다. 배경은 화면 너비로 펼치고, 문구는 넓은 컨테이너 안에 정렬한다.

### NEW ARRIVALS

- 구역은 위쪽 패딩 약 75px, 아래쪽 패딩 약 90px을 사용한다. 1200px 컨테이너 내부 카드 영역 높이는 약 821px이다.
- 카드 사이의 가로 간격은 **22px**이다. 위·아래 카드 줄의 간격도 22px이다.
- 위쪽 줄: 왼쪽 `392 × 205px` 카드가 제목 아래에서 시작하고, 오른쪽 `786 × 360px` 카드가 맨 위에서 시작한다. 두 카드의 x 위치 차이는 `392 + 22 = 414px`이다.
- 아래쪽 줄: 왼쪽 `392 × 292px`, 가운데 `450 × 439px`, 오른쪽 `314 × 292px`. 각 카드 사이가 22px이며 `392 + 22 + 450 + 22 + 314 = 1200px`이다.

```text
1200px 컨테이너
┌─ 제목 ────────┐ 22px ┌────────── 오른쪽 상단 카드 786px ──────────┐
│ 왼쪽 상단 카드 392px │    │                                           │
└─────────────────┘    └───────────────────────────────────────────┘
                   아래 줄까지 22px
┌── 왼쪽 392px ──┐ 22px ┌── 가운데 450px ──┐ 22px ┌─ 오른쪽 314px ─┐
└───────────────┘      └──────────────────┘      └───────────────┘
```

### BEST PRODUCT와 영상

- BEST PRODUCT는 제목과 설명을 중앙 정렬하고, 아래에 상품 분류 탭 4개를 둔다. 탭은 각각 약 157px 너비다.
- 상품 카드는 가로 스크롤 목록이다. 1440px 화면에서 카드 하나는 약 266px, 카드 간격은 약 18px이다. 일반적인 여러 행 그리드로 줄바꿈하지 않는다.
- 상품 목록 아래에는 `DRAG & SCROLL` 안내가 있다.
- 영상은 전체 너비 영역이다. 높이는 화면 너비에 따라 변한다. 1440px 뷰포트에서 약 802px, 1920px 뷰포트에서 약 1072px이었다.

### 뉴스·문의·브랜드스토어와 푸터

- 뉴스/문의/브랜드스토어는 넓은 1400px 컨테이너 안에서 `700px + 350px + 350px`의 3열로 이어진다. 세 열의 높이는 약 355px이다.
- 문의와 브랜드스토어는 각각 제목, 설명, 하단 버튼을 같은 높이에 배치한다.
- 푸터는 최대 1400px이다. 위쪽 줄에는 로고·정책 링크, 아래쪽 줄에는 회사 정보·고객센터·패밀리 사이트가 들어간다.

## 작은 화면 확인

- 원본 페이지는 390px 뷰포트에서도 문서 너비가 약 1262px까지 늘어나 가로 스크롤이 생긴다. `NEW ARRIVALS`의 1200px 배치도 유지된다.
- 따라서 원본을 그대로 재현하는 경우와 모바일에 맞게 새로 반응형 배치를 만드는 경우를 구분해야 한다. 모바일 재설계가 목표라면 카드 쌓기와 가로 상품 스크롤은 별도 규칙으로 정의한다.
